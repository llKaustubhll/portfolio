# portfolio
Personal portfolio of Kaustubh Pande, a Digital Marketing Executive and freelance marketer, showcasing SEO, social media strategy, content creation, brand campaigns, and selected client projects.

## Local development

This portfolio uses plain HTML, CSS, and JavaScript; no dependencies or build step are required.

From `/workspace/portfolio`, run:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Edit `index.html` to personalize experience, services, projects, and contact details. Draft placeholders do not represent verified experience or results. `styles.css` contains responsive layouts; Google Fonts is optional and falls back to system sans-serif fonts. Check JavaScript with `node --check script.js`.
